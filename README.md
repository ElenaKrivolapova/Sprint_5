## Описание проекта

Автотесты для сайта DOSKA с использованием:
- Python
- Pytest
- Selenium WebDriver

Проверяются основные пользовательские сценарии:
регистрация, авторизация, выход из аккаунта, создание объявления.

---

## Структура проекта

### tests/

Папка с тестами.

- `test_registration.py` — тесты регистрации пользователя  
- `test_login.py` — тест успешного входа  
- `test_logout.py` — тест выхода из аккаунта  
- `test_create_ad.py` — тест создания объявления авторизованным пользователем  
- `test_create_ad_unauthorized.py` — проверка создания объявления без авторизации  

---

### Основные файлы

- `conftest.py` — фикстуры
- `locators.py` — локаторы элементов страницы
- `data.py` — тестовые данные (url, email, пароль, значения полей)
- `.gitignore` — исключения Git
- `README.md` — описание проекта
